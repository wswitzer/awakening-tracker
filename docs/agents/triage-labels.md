# Triage Labels

Canonical triage-role vocabulary for this repository:

- `needs-triage` — incoming work not yet understood
- `needs-info` — blocked on missing information
- `ready-for-agent` — sufficiently specified for autonomous implementation
- `ready-for-human` — requires a human decision or action
- `wontfix` — deliberately not planned

These names are part of the repository agent contract. If GitHub repository labels are renamed later, update this mapping deliberately rather than creating a second vocabulary.
